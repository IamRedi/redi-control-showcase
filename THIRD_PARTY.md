# Dependencies and attribution

The evaluation license applies to first-party REDI CONTROL work. Dependencies
retain their own licenses. npm workspace manifests and the lockfile record
Next.js, React, Fastify, TypeScript, PostgreSQL client, validation, test and
browser dependencies. No node_modules directory, browser binary or dependency
cache is committed. PostgreSQL is a separate runtime, not vendored source.

The local native PostgreSQL 17.11 package came from the PostgreSQL project's
[official Ubuntu Apt repository](https://www.postgresql.org/download/linux/ubuntu/).
Its downloaded artifact was checked against repository SHA-256 metadata and
extracted into the task's isolated runtime, without a system installation.

Original private context PDFs and the supplied UI-reference image are omitted.
New screenshots show the actual first-party application with synthetic data.
Hero/social graphics frame those captures. Videos are silent captioned montages,
not physical footage, live provider executions or continuous screen recordings.
No external news story, account media, customer screenshot or vendor render is
used as public presentation evidence.
