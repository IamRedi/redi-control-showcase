# Media and proof boundaries

The photographs are screenshots of the actual running REDI CONTROL web app,
backed by an isolated PostgreSQL 17 database and fictional Aurora Media fixture.
No real social account, provider metric, customer content or owner installation
is shown. The top notice identifies evaluation data and disabled providers.

The DE/EN videos are silent captioned montages of those screenshots. Editorial
hero/social cards are layouts using actual captures. They do not fabricate UI.
The browser acceptance route list and the artifact checksums record what was
captured. Source contracts, local tests, browser behavior, CI, production and
real-provider acceptance remain separate evidence levels.
