# Contributing to the evaluation snapshot

This repository is a presentation/evaluation copy. It does not authorize product
milestones, deployments, real account connections, provider calls or production
operations on the original system. Preserve tenant isolation, RLS, approvals,
idempotency, audit/outbox, SSRF and secret boundaries. Never weaken an assertion
or security limit for presentation purposes.

Use `npm run check`, disposable PostgreSQL integration tests and the offline
boundary/browser checks. Keep fixtures fictional and external providers disabled.
The frozen work-standard document remains byte-identical and its original hash
check remains enabled. Its presence is not a claim of RWS Core Conformance or
production readiness. Private operator/history controls were intentionally omitted.

Media changes require actual application capture, lineage/checksums and owner
review before public publication. Keep credentials, runtime tokens, databases,
local environments and private reports out of Git.
